社招候选人自训练系统 · v0
你的笔记、手册和 key 不经过任何服务器。所有内容只存在这个浏览器里；导出即备份。

用之前，先看三步

  1. 这是什么。 用 AI 训练你，不是用 AI 面试你。它不替你答题，训练的是你的应答结构和你对岗位、行业的认知。三个模块：面前预演（A）→ 面试 → 面后复盘（B）→ 结果回填（C）→ 手册长一行 → 下一次 A。每次预测都会被真实结果打分，纠正写回你的手册；这轮没过，样本也在长。 
    A 面前预演 → 面试 → B 面后复盘 → C 结果回填 → 手册更新 → 下一次 A
  2. 数据在哪。 本页是纯静态页。手册、笔记、转录、API key 全部只存在这个浏览器的本地存储里，不经过任何服务器。跑模块时，浏览器直接把协议 + 分类库 + 你的输入发给你自己填的模型接口，不经过第三方。清浏览器数据 = 清空一切，所以请定期导出手册。
  3. 前提。 这不是捷径：JD 和简历都必须给，笔记要你自己写，空位要你自己填。只对愿意对自己诚实的人有用：工具无法防止你给自己写有利的笔记，它的每条判断只和你的笔记一样好。覆盖一位候选人的面试，不分社招校招；群面不覆盖。网页是零门槛试用，Claude Code skill 才是完整版（本地转录、手册自动写回）。

个人手册（只存在本浏览器）

模板来自 templates/handbook.md。跑完 B 或 C 后，把下面"待合并的手册增量"手动合并进来。自动保存。

待合并的手册增量（来自最近一次 B / C 输出）

模块 A · 面前预演

输出：错位拦截与硬门槛 → JD↔证据映射 → 类型预判与骨架 → 5 分钟核对单 → QA 预案（结构 + 参考句）→ 带标记的自介半成品。不写答案全文，不预测通过率。

模块 B · 面后复盘

笔记模板能填多少填多少：填不全，模型会按材料完整度只问缺的 3–5 个问题。底部三个计数字段是硬信号的唯一依据，问不出 = 无法判断。输出固定三段：结论卡 / 明细 / 自检。

模块 C · 结果回填

一行字。写回场次记录；与 B 的预测比对；不一致则加一条校准记录。不推测原因，不建议下一步。

录音转录（实验性入口）

录音前确认对方同意及当地法律。音频只在本页内存里，不上传、不保存到服务器；关闭页面即消失。

两种转录方式，都由你主动触发：① 浏览器本地开源语音模型（首次需下载模型文件，之后离线可用）；② 你自己的语音接口 key（OpenAI 兼容 /audio/transcriptions）。本页不内嵌任何 key。

模型与 key（只存本浏览器）

协议与分类库随本页离线缓存。每次运行把 PROTOCOL + taxonomy 五个文件 + 你的输入一起发给上面的接口；Anthropic 接口对协议部分启用提示缓存以降低费用。
