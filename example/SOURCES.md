# 虚构样本的行业校准来源

> `example/` 里的候选人、公司、经历、数字全部虚构。但行话、指标口径、政策背景和数量级参照下列公开资料，避免外行表述。只列政策与行业类来源，不列任何公司页面。

## 集采（高值耗材带量采购）
- 2021-09 国家组织人工关节集采：髋关节均价约 3.5 万元降至 7,000 元左右，膝关节约 3.2 万元降至 5,000 元左右，平均降价 82%；首年意向采购量 54 万套，占医疗机构总需求量 90%；48 家企业参与、44 家中选。（新华社 / 界面新闻 / 健康界报道，2021-09）
- 2022-09 国家组织骨科脊柱类耗材集采：平均降价 84%；覆盖颈椎、胸腰椎融合固定、椎体成形、椎间盘镜、人工椎间盘 5 大类 14 个产品系统类别；首年意向采购量 109 万套；171 家企业参与、152 家中选。（新华网 2022-09-27、央广网 2022-10-06）
- 行业用语：中选 / 落地 / 带量 / 意向采购量 / 中选医院 / 挂网 / 入院 / 上量 / 台次。

## 手术机器人
- 2024 年国内手术机器人新增装机量超 300 台；骨科手术机器人国产化率超 70%，向二级医院、县级医院渗透；头部国产骨科机器人品牌累计手术量 2024 年底超 10 万例（2022 年底超 3 万例，2023 年底超 6 万例）。（中国食品药品网 2025-06、新浪财经 2024-12、行业年度中标数据）
- 2025 年骨科手术机器人中标超 100 台，市场规模同比增约 35%。
- 收费与医保：2024-01 国家医保局《手术与治疗辅助操作类医疗服务价格项目立项指南（试行）》；DRG 3.0 分组方案首次把机器人辅助手术单独分组，骨科机器人加收封顶 12,000 元、腔镜机器人封顶 26,000 元；未上传设备运行记录的机构执行减收。北京已将机器人辅助手术及一次性骨科机器人手术配件纳入医保支付。（国家医保局文件；新浪健康 2026-09；钛媒体 2026）
- 行业用语：装机医院（installed base）/ 开机率 / 单台月手术量 / 一次性配件（机器人专用耗材）/ 术式渗透率 / 首台手术 / 常规开台 / 跟台 / 带教 / 术者培训中心 / 解剖工作坊 / 手术观摩。

## 学术推广合规
- 2023-07 起为期一年的全国医药领域腐败问题集中整治；卫健委口径：规范的学术会议和讲课费本身不违规，整治的是虚假会议与利益输送。（澎湃新闻 2024；汉坤、中伦律师事务所合规文章）
- 2024-03-01《刑法修正案（十二）》施行，医疗领域行贿从重处罚；2024-03 河南省市场监管局《医药生产经营企业防范商业贿赂行政指引》。
- 行业用语：讲课费 / 赞助 / 卫星会 / 科室会 / 病例讨论会 / KOL / 学科带头人 / 阳光合规 / 反商业贿赂。

## 医疗器械广告
- 2020 年国家市场监管总局令第 21 号《药品、医疗器械、保健食品、特殊医学用途配方食品广告审查管理暂行办法》：器械广告发布前须经广告审查机关审查，按审查通过的内容发布；只出现产品名称的不需审查；不得含疗效承诺、治愈率等表述。（中国政府网公报 2020 年第 7 号；北京市市场监管局合规指引 2023-01）

## 岗位要求（招聘网站公开 JD 的共性）
- 手术机器人厂商市场 / 大客户岗：本科及以上，医学、生物医学工程、市场营销等相关专业优先；5 年以上医疗设备经验，其中大型设备 3 年以上；熟悉招投标、医疗器械采购流程与政策；严格遵守行业法规与公司合规政策。
- 骨科关节线市场 / 产品经理岗：本科及以上，医、药类相关专业；5 年以上行业市场经验；职责含学术推广、手术跟台、科室会、KOL 网络建设与维护、区域学术会议策划执行、经销商开拓维护、竞品与政策分析。
- 临床应用 / 术式推广岗：临床医学、生物医学工程等背景；负责手术跟台支持、系统配置、术中保障。
- 结论：市场与临床市场岗的学历门槛是本科及以上、硕士优先；博士要求出现在研发和医学事务岗，不出现在市场岗。样本候选人设定为临床医学硕士、做过一年骨科住院医师后转行，符合"临床背景优先"的行业偏好。
