# 应答骨架 A–J（cn）

> 骨架是回答的结构，不是答案。协议不生成话术全文，"下次这样说"只指向骨架编号 + 一行结构。
> 例句全部虚构（虚构候选人：骨科植入物临床市场岗），只示范结构，数字不可引用；行话与量级参照 `example/SOURCES.md`。

---

## 骨架 A · 判断 + 依据 + 反悔条件

用于：类型 A / C；任何"你怎么判断""你为什么这么做"。

```
我的判断是 X。依据是 [数据 / 实验 / 竞调]。如果 [指标] 低于 [阈值]，说明判断错了，切换到 [备案]。
```

例（虚构）："我的判断是把下半年预算先压到 62 家集采中选医院里 18 家还没开台的。依据是中选后 12 个月它们采购量为零，但骨科门诊量在区域前 40%。如果两个季度后开台的少于 10 家，说明判断错了，预算切回已开台医院的上量。"

## 骨架 B · 归因分解

用于：类型 B；任何"这个增长哪部分归因给什么"。

1. **时序拆分**：动作分阶段上线，每阶段增量单独记账
2. **漏斗定位**：线索 → 首次触达 → 有效沟通 → 成交，每环折算到最终指标
3. **诚实兜底**："交叉部分无法完全归因，整体看组合动作 ROI，单环节用于止损判断"

例（虚构）："膝关节月均台次 310 到 540。集采落地后第一个季度涨的 120 台记价格效应；带教中心第二季度上线，记 70 台；剩下 40 台是交叉的，我不硬归因，整体看组合投入产出，单环节只拿来判断要不要停。"

## 骨架 C · 受控示弱

用于：所有类型；离职原因、最大短板、缺口条目。

```
[具体领域] 是行业语言差，[时限] 内补齐，底层 [方法] 可迁移。
```

例（虚构）："机器人一次性配件的定价和 DRG 分组下的收费落地是行业语言差，两个月内补齐，底层的术式推广路径可迁移。"

**永不交付**：表达类、结构类、数据类缺陷；永不把岗位名说小（"负责 X 的支持""协助 Y"都是把岗位说小）。

## 骨架 D · 可搬运一句话

用于：类型 D；任何需要对方转述给第三人的证据。

```
动作 + 一个数字 + 状态词。
```

例（虚构）："单髁置换术者培训路径，48 位主刀完成首台，术式渗透率 9% 到 17%。"

## 骨架 E · 边界收口

用于：类型 C；任何问到你能力边界的地方。

```
这块我做到 [应用层 / 策略层]，[工程层 / 专业层] 的 X 我判断不了，需要 [角色] 配合。
```

例（虚构）："这块我做到临床市场层，机器人导航精度和注册证适用范围的 X 我判断不了，需要临床支持和法规事务配合。"

## 骨架 F · 框架 + 评估 + 证伪

用于：类型 F；任何"你怎么看 X""怎么评估 / 怎么证伪"。

```
点数复述 → 框架 → 每维度指标 → 证伪条件 → 案例填一格（≤ 90 秒）
```

例（虚构）："您问的是三层：入院、开台、上量。入院我看中选医院覆盖率，证伪条件是两个季度不涨；开台我看首台转化；上量我看月均台次；案例只讲开台这一格。"

## 骨架 G · 组织架构反向提问

用于：所有类型，**每场必问一个**。目的是验证协同难度和岗位实权，不是礼节。三选一：

- "这个岗位所在的板块，和 [相邻板块] 是平行还是同一个负责人？"
- "岗位有没有自己负责的机制或指标？"
- "直接负责人自己还带业务 / 带项目吗，还是只配资源？"

## 骨架 H · 案例题前置检索

用于：类型 A-2；任何"如果是你怎么做"。答题前三问，**顺序不能反**：

1. "咱们现在这块的现状 / 构成是什么？"（先知道对方在做什么）
2. "有什么是明确不能做的？"（先知道禁区）
3. "目标用户的画像是？"（再问人）

然后：分路线框架，每条 ≤ 90 秒，把红线写进方案，3 分钟收口。
先问画像后问现状，答出来的方案会落在对方根本不做的渠道上。

## 骨架 I · 方向题

用于：类型 G；任何"你想往哪走"。

```
我的能力区间是 [X]。我想要的挑战不是换领域，是把这个区间的天花板打出来、再复制给别人——[对方刚提到的岗位 / 团队] 就是这个。
```

禁止出现："舒适区""想尝试没做过的""做什么都一样"。

## 骨架 J · 隐性用户题

用于：任何"你自己用 / 买 / 玩吗"。

```
我不是核心用户。[过往行业] 时我也不是 [该行业的目标用户]——我靠决策链拆解用户，不靠自己是用户。[如有] 我个人 [简短事实]，但这不是我理解用户的依据。
```

例（虚构）："我不是核心用户。我做过一年骨科住院医、上过台，但后来五年我不是术者——我靠拆术者的决策链理解用户，不靠自己是用户。"
