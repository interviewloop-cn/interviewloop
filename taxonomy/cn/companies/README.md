# companies/ · 公司索引（发布时为空）

本目录只放按 `templates/zh/contribute-company.md` 提交的公司索引记录。作者自己的面试记录**永远不进**这里。

## 一条记录包含什么（字段固定，不得增删）

- 公司（招聘页上的公开名称）
- 岗位大类
- 轮次结构（几轮、每轮身份，只写职务或层级）
- 每轮观察到的面试官类型（只写 `interviewer-types.md` 的编号，允许"未分类"）
- 业务阶段（只写 `stages.md` 的阶段名）
- 来源（公开链接，或"本人面试"）
- 日期（年-月）

## 禁止

- 人名（含面试官姓名、任何可识别到个人的描述）
- 评价性语言（"面试官很水""流程混乱"）
- 薪资数字、内部数据
- 对结果的解释（"因为 X 所以没过"）

## 规则

- 转录片段、问题原文可写，但去掉人名和任何可识别到个人的描述。

- 一家公司一个文件，文件名为公司公开名称的拼音或英文。
- 同一公司多条记录追加在同一文件，按日期倒序。
- 合并节奏不承诺。
