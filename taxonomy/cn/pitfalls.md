# 常见失分模式库（cn）

> 每条：模式名 / 识别方法 / 典型触发场景 / 对应骨架。只抽模式，不含任何具体案例。
> 顺序是作者样本里的危害排序。模块 A-5 无个人手册时取前 3 条；模块 B-4 只用本文件的模式名，新发现进"待定观察"。
> 表达类瑕疵（口头禅密度、语速）不在本库：它们由模块 B-5 计数，不进失分模式，也不进结果预测。

---

## 1. 弹药滞后

- **识别方法**：最强的机制级证据在自介和前 10 分钟没出现，留到结尾或根本没说。自介第一句出现"支持 / 协作 / 配合 / 帮助"类降级词。
- **典型触发场景**：自我介绍；"先介绍一下你自己"；面试官开场就追一个具体问题导致自介被跳过。
- **对应骨架**：D（可搬运一句话，第一分钟内出一个带数字的机制级证据）；A-7 自介结构。

## 2. 归因无预制件

- **识别方法**：被问"这个增长哪部分归因给什么"时现场拆，拆不出层次，或用"整体效果好"带过。
- **典型触发场景**：类型 B 追口径；简历上任何"从 X 到 Y"的数字被追。
- **对应骨架**：B（时序拆分 / 漏斗定位 / 诚实兜底）。

## 3. 反问确认误用

- **识别方法**：数据类单句问题也先反问确认，节奏被拖慢；或多层问题不点数就直接答，漏层。
- **典型触发场景**：类型 B 短平快追数；类型 F 多层抽象题。
- **对应骨架**：无专属骨架。规则：数据类单句问题直接答；多层问题逐层点数后再答（骨架 F 的第一步）。

## 4. 自我降级

- **识别方法**：压力下主动交出"表达 / 结构 / 数据"类缺陷；或把岗位名说小（"负责 X 的支持"）。
- **典型触发场景**：最大短板题；被追问后接不上；自介第一句。
- **对应骨架**：C（受控示弱：只交行业语言差 + 时限 + 可迁移方法）。

## 5. 观点替代方法

- **识别方法**：被问"怎么评估 / 怎么证伪 / 怎么判断"时给了结论，没给评估设计（指标、阈值、证伪条件）。
- **典型触发场景**：类型 F；任何"你怎么看 X"。
- **对应骨架**：F（框架 + 评估 + 证伪）；A（反悔条件）。

## 6. 案例失控

- **识别方法**：单个案例超过 90 秒；案例题总作答超过 3 分钟；讲到面试官打断或换题。
- **典型触发场景**：类型 A-2 案例题；"讲一个你最有成就感的项目"。
- **对应骨架**：H（每条路线 ≤ 90 秒，3 分钟收口；超过就停下来问"这个方向您要不要我再展开"）。

## 7. 检索顺序错

- **识别方法**：案例题答之前问了用户画像，没问业务现状和禁区；方案落在对方不做或不能做的渠道上。
- **典型触发场景**：类型 A-2 "如果是你怎么做"；强监管行业。
- **对应骨架**：H（三问顺序：现状 → 禁区 → 画像）。

## 8. 隐性题没接

- **识别方法**："你自己用 / 买 / 玩吗"被当成事实题回答，答了自己的使用习惯，没接"你是不是目标用户、不是的话怎么理解用户"这一层。
- **典型触发场景**：类型 A-2 中后段；任何 C 端产品岗。
- **对应骨架**：J（隐性用户题）。

## 9. 方向题矛盾

- **识别方法**：面试官递台阶（"你这块经验很稀缺"），候选人接"那是舒适区，我想要新挑战"，把台阶推开；方向陈述与自己的能力区间相反。
- **典型触发场景**：类型 G "你想往哪走"；任何转推场景。
- **对应骨架**：I（方向题）。

## 10. 听题偏

- **识别方法**：抽象名词类问题（监管、环境、尺度、机制）第一遍答偏，面试官重问一次。
- **典型触发场景**：类型 C / F；行业约束类问题。
- **对应骨架**：无专属骨架。规则：先复述一句"您是问 X 还是问 Y"，再答（骨架 F 第一步的点数复述）。

## 11. 功劳交出

- **识别方法**：讲成果时主动加"后面不是我负责了""这块主要是别人做的"，把可归自己的累计数字交出去；或口径清单里的几个数只上了一个。
- **典型触发场景**：类型 G 逐段还原经历、问权限边界；任何"这个是你做的吗"。
- **对应骨架**：D（可搬运一句话，口径清单里相关的数一起上）。与"如实答权限边界"不冲突：权限如实，功劳不多交。
